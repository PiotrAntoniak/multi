# XGBoost topic classifier — per-language × pooling grid (lenient labels)

Generated by `xgboost_topic_optuna.py --mode merge --labels lenient` — xgboost 3.2.0, optuna 4.8.0, `tree_method=hist`, `max_bin=64`, 2 threads per worker. No cross-lingual transfer.

**Label scheme: `lenient`** — raw comma-tags are mapped onto the 8 canonical tags via the curated aliases in `audit_labels.md` §1 (singular/plural, `crime`/`law` → `crime and law`, `science/*`/`science and technology` → `science`, misspelling `sciece` → `science`, `tourism`/`accomodation` → `travel`, `disasters and accidents`/`accident` → `safety`, `politics and conflicts` → `politics`, plus country/continent tags → `geography`). This recovers the large fraction of positives that exact-string matching drops and cuts all-zero rows from 1147/2009 (strict) to ~504/2009.

**Thresholds: per-tag tuned.** For each tag the threshold in 0.05..0.95 (step 0.05) maximising that tag's F1 on the model's own training-set predictions is chosen in-sample (dev for the dev-trained model, dev+devtest for the dev+devtest model) and then applied to the evaluation split. The Optuna search itself is unchanged: it still maximises devtest macro-F1 at the fixed 0.5 threshold.

Protocol: baseline (default params) and every Optuna trial (TPE seed 0, shared search space) train on `dev` (997) and score `devtest` (506); the best params are retrained on dev+devtest (1503) and evaluated on `test` (506).

## Notes

- **Winning mode per language (tuned `test` macro-F1):** en `mean` (0.5281), it `mean` (0.4640), de `mean` (0.4702), fr `mean` (0.5025).
- **Best mode overall (mean tuned `test` macro-F1):** `mean` (mean 0.4912, bos 0.3058, eos 0.3577, lead 0.2574).
- **Macro rule:** macro-F1 is reported over all 8 tags (tables a/b/c) and over the tags whose full-dataset positive count is >= 50 (table d). Qualifying tags (`n_tags_ge50`) = en 8, it 8, de 8, fr 8. With lenient labels all 8 tags qualify (full-dataset counts are 81-518), so table (d) equals table (a); the rule is stated so it can be re-checked under a different label scheme.
- **`devtest → test` shift of the tuned model (mean over modes):** en +0.0491, it +0.0836, de +0.0442, fr +0.0472. The per-tag thresholds are tuned in-sample on the training split, so `test` remains an out-of-sample read; a negative shift is selection optimism.
- **Reproducibility:** lenient labels + per-tag tuned thresholds. Per-mode trials: `xgboost_perlang_lenient_trials_{lang}_{mode}.csv`; full metrics (fixed and tuned) with per-tag thresholds: `xgboost_perlang_lenient_{lang}.json`.
