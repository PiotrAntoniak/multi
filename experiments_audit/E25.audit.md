## Verdict on "610m shrinks the gap on every dataset"

- **Signed gap `diag − off` (the value shown in the table): false for PAWS-X.** It goes
  **−0.012532 → +0.003199**, a signed **increase of +0.015731**; it crosses zero. The other seven
  datasets shrink.
- **Absolute gap `|diag − off|`: true for all eight.** PAWS-X `|gap|` falls 0.012532 → 0.003199
  (4× smaller). The same holds for the secondary AUC gap (−0.017389 → +0.008025 signed; |gap|
  0.0174 → 0.0080).
- The entry's last column already says "closed" for PAWS-X rather than "smaller", which contradicts
  the blanket "every dataset" sentence.
- Precision: the claim is true only if "gap" is redefined as `|diag − off|`. Say that explicitly,
  or say "signed gap shrinks on 7/8; PAWS-X crosses zero".

Additional qualification: on `flores_agg` and `mel` the 610m **diagonal is lower**
(0.544→0.510, 0.588→0.577), so part of those gap reductions is lower in-language quality, not
better transfer. On toxic the all-pairs macro-F1 gap shrinks (0.171→0.152) but the English→target
macro-F1 gap is flat (0.342→0.341); the all-pairs improvement comes from non-English→English.

## Discrepancies

1. **"610m shrinks the gap on every dataset"** — false for the signed gap on PAWS-X (see verdict);
   true only for `|gap|`. Also, on flores_agg/mel the shrink is partly a lower diagonal.
2. **"PAWS-X transfers at parity"** — numerically true (0.532 vs 0.520 at 210m; 0.558 vs 0.561 at
   610m), but both sides are near chance: EN self AUC 0.530 (210m) / 0.628 (610m), macro-F1 0.510 /
   0.575. The 210m "cross-lingual beats in-language" is because English is the weakest language
   (en 0.510 vs de 0.524/fr 0.527/es 0.517), not because transfer is strong. E24's EN-self AUC is
   0.602 (train-only, 400 trees); E25's is 0.530 with train+val. Do not present this as a success.
3. **"largest gaps on MultiEURLEX/textdetox"** — true for the all-pairs macro-F1 column (mel
   0.258/0.160; textdetox 0.198/0.158). Not true for English→target: the largest English-centric
   gap is toxic (macro-F1 0.342/0.341; AUC 0.231/0.209). The entry does not say the column is
   all-pairs, so this reads as an English-transfer claim.
4. **Missing protocol facts in the entry.** The E25 table has no metric column, no language sets,
   no test n, no seed, no cap, and no statement that "cross-lingual" = all ordered off-diagonal
   pairs. E18's approved style includes an inputs table and a protocol paragraph; E25 does not.
   A reader can mistake the numbers for E18's micro-F1-qm (mel) or E24's AUC/train-only (PAWS-X).
5. **"test is the full standard split" is false for flores_sent/agg.** `lang_matrix.md:5` and the
   script docstring (`:23-25`) say this, but `load_flores_sent` (`:299-303`) and `load_flores_agg`
   (`:327-336`) put half of `devtest` into val: test is 505 (sent) and 139 (agg), not 1009/279.
6. **flores_agg/mel diagonal drops at 610m** — 0.544→0.510 and 0.588→0.577. The table shows this
   but the "smaller gap" column hides that it is partly a lower in-language score. On agg the drop
   is en 0.564→0.466 and de 0.590→0.476 while fr rises 0.464→0.559; with 139 test rows this is
   noisy (inference: overfit/small-sample, not proven).
7. **Toxic directionality** — the all-pairs gap shrinks 0.171→0.152, but en→others macro-F1 is
   0.422→0.429 and the en-centric gap is 0.342→0.341 (flat). The all-pairs gain is mostly
   others→en (0.642→0.687). The entry's "610m shrinks the gap" on toxic does not mean better
   English→target.
8. **Rounding presentation** — gap is from unrounded cells; subtract the displayed diag/off and you
   can get ±0.001. State this, or display 4 dp.

## Bugs / risks

1. **textdetox duplicate leakage (confirmed, small).** `load_textdetox` (`:466-493`) splits 80/10/10
   per language by row, but the dataset repeats texts within a language. Test rows with an exact
   text in that language's train split: **en 17/500 (3.4%), it 5/500 (1.0%), de 62/500 (12.4%),
   fr 30/500 (6.0%), es 0/500 (0%)**. On a train-only reproduction, macro-F1 on the non-duplicated
   subset drops by **−0.0173 (de), −0.0080 (fr), −0.0031 (en), −0.0021 (it), 0.0000 (es)**. This
   inflates the textdetox diagonal and, to a smaller degree, its gap. Cross-language exact overlap
   is 0, so the off-diagonal is not directly leaked.
2. **PAWS-X train+val is harmful (confirmed, material).** E25 trains on train+val (`:708-711`).
   Reproduction from the stored arrays at 250 trees: train-only AUC **0.5813**, train+val **0.5284**;
   adding 2k extra *train* rows instead gives 0.5910. At 400 trees, E24's train-only EN-self AUC is
   0.602 vs E25's 0.530. PAWS-X val and test share 1,339 sentences (train shares 0), so this is a
   dataset-construction effect, but it means the PAWS-X row is not comparable to E24 and the parity
   is protocol-dependent. Recommendation: train on train only for PAWS-X, or report both.
3. **All-pairs off-diagonal hides direction and class priors.** Toxic 210m: en→others macro-F1
   0.422 / AUC 0.672 vs others→en 0.642 / AUC 0.784. The average 0.567 / 0.725 overstates the
   English→target result. The same pattern is smaller on textdetox (0.637/0.694 vs 0.738/0.805).
4. **Gap conflates in-language quality with transfer.** A lower diagonal mechanically shrinks the
   gap. flores_agg/mel show this. Report diagonal and off-diagonal separately, not only the gap.
5. **Cell checkpoint staleness (latent).** `run_row` (`:687-693`) returns any existing
   `dataset__backbone__lang.json` without checking a meta/split hash. If the split, cap or labels
   change, old cells are silently reused. Current cells are all from this run, so no numerical
   impact. Add a hash of `meta.json` to the cell key/contents.
6. **flores_agg silent URL mapping (latent).** `:320-323` maps a URL spanning multiple sentence
   splits to `None` and then `fillna("devtest")`; `train_flores12.prepare_agg` (`:354`) raises in
   that case. Current data has 0 spanning URLs, so no impact; the two implementations disagree on
   failure behavior.
7. **textdetox RNG re-seeded per class (minor).** `:477` creates `RandomState(0)` inside the class
   loop. It is deterministic, but it is not one joint stratified shuffle. No result bug observed.
8. **mel constant-label skip (latent).** `fit_model` (`:611-620`) skips a label whose train column is
   constant and leaves its score at 0. No label is constant in this run (min positives 101), so no
   impact; a future split could silently lose a label.
9. **No CIs / no predictions.** One seed, and test n is 139 (agg), 204 (sib200), 500 (textdetox),
   505 (sent). The 0.003 PAWS-X gap and the 0.014 xnli gap **change** are not distinguishable from
   noise. No per-cell predictions are stored, so CIs or alternate thresholds require a re-run.
10. **Parallel test sets.** FLORES, MEL, XNLI and SIB200 test items are largely shared across
    languages (labels identical / 99.4–100% for PAWS-X). The matrix measures translation invariance
    on the same items, not generalization to new target-language items. textdetox is **not**
    verified as cross-language aligned: full label sequences differ for it/de/es and exact
    cross-language text overlap is 0; its test label vector is `[0]*250 + [1]*250` for every
    language by construction, not evidence of aligned items.
11. **Metric mismatch with E18/E24.** E18 mel is micro-F1 with quantile-matched target thresholds;
    E25 mel is macro-F1 at 0.5. E24 PAWS-X is AUC, train-only. The entry gives no metric, so the
    numbers invite invalid cross-entry comparison.
12. **`render` writes MD/PNG non-atomically** (`:908-956`); JSON is atomic. Minor.

## Recommended changes

1. Reword the finding: "610m reduces `|diag−off|` on all 8 datasets; the signed gap shrinks on 7/8;
   PAWS-X crosses zero (−0.0125 → +0.0032)." Do not say "shrinks on every dataset" next to a signed
   gap column.
2. Add a metric column (macro-F1 everywhere; mel multilabel@0.5; AUC secondary), the language sets,
   test n, seed, caps, and the definition "off-diagonal = all ordered pairs, not English→target".
3. Add an English→target column (en→others) or a second table. Report diagonal/off-diagonal
   per language, or at least their ranges.
4. For PAWS-X, train on train only (matching E24) or report train-only and train+val side by side;
   add the AUC row, because macro-F1 at 0.5 is near the balanced baseline.
5. Make the textdetox split duplicate-aware (group identical texts before splitting) and report the
   score on a clean test subset; or state the leakage and its measured size.
6. Fix `lang_matrix.md:5` and the docstring: test is half of `devtest` for flores_sent/agg, not the
   full standard split.
7. Add multi-seed runs or bootstrap CIs for the small datasets (agg 139, sib200 204, sent 505,
   textdetox 500) before calling 0.003–0.02 differences real.
8. Add a split/meta hash to the cell checkpoint (and JSON meta) so stale cells cannot be reused.
9. Make `flores_agg`'s URL mapping fail loudly if a URL spans splits, matching
   `train_flores12.prepare_agg`.
10. State that mel macro-F1@0.5 is not E18's micro-F1-qm and that E24's PAWS-X is AUC/train-only.
