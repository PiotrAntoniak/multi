## Bugs / risks

### Code-level (low severity for this run)
- `merge_shards` (`alllang_vs_perlang.py:519-547`) takes `meta` from the first shard, so
  `meta.finished` is not the true completion time. It also does **not** assert that all expected
  `(dataset, backbone)` cells are present; a partial shard set would produce a plausible-looking
  partial JSON.
- All shards write the same `STATUS_PATH` (`:84`, `:125-133`); the last writer wins. The stored
  status says `flores_agg/610m` at 07:07:05 while the toxic shards were still training. Operational
  only.
- `_mean_over` uses `np.nanmean` (`:331-332`), silently averaging fewer languages if an AUC is NaN.
  No NaN occurs in this run, but there is no warning.
- The +/-0.002 verdict deadzone (`:344-345`) is hardcoded and not stated in the entry.
- `micro_f1` equals `accuracy` for single-label multiclass (`:175-182`); the MD reports both, but
  they are not independent evidence.
- `--smoke` truncates each split to the first 1,500 rows without shuffling (`:202-205`, `:573-574`);
  smoke metrics are not comparable to the stored run (smoke files live only in TMP).
- The docstring counts the script itself among the "four files only", but the run also writes
  `--tag`/`--merge` shards in TMP. Documentation-only inconsistency.

### Design-level (these limit the claim, not the arithmetic)
- **Data-size confound.** All-langs sees 4x the FLORES rows and 4x-10x the toxicity rows. There is
  no matched-row or equal-capacity control. On FLORES, "more rows" is specifically four translations
  of the same 997 documents, with the same labels; the gain may be translation augmentation rather
  than multilingual label diversity. On toxicity, the per-lang win survives more pooled data, which
  makes that conclusion the stronger of the two.
- **Toxicity threshold / prior.** Fixed 0.5 threshold, no validation calibration; per-language
  positive rates are 11.7% (en) to 36.5% (fr) and the pooled prior is different. Macro-F1 is
  threshold-sensitive. AUC also drops on every language (-0.0004 to -0.017), so this is not purely a
  threshold artifact, but the F1 gap is amplified by it.
- **Language imbalance in the pooled model.** Toxic pooled training is dominated by en (24,000) and
  fr/es (21,011/23,349) vs de (9,836). No sample weights or balanced pooling; small-language
  dilution is a plausible part of the de/it losses.
- **Single seed / small tests.** One seed, no CI; agg test n = 139, sent = 505. The bold +0.101 and
  the Italian +0.060/+0.034 are the noisiest cells.
- **Metric dependence.** Italian at 210m is better on AUC but worse on macro-F1; the entry's
  "only at 610m" sentence is true only for macro-F1.
- **Cross-language data residue.** 1 es-train/fr-test duplicate and 2 fr/es train duplicates (one
  with contradictory labels) survive per-language dedup. That is 1 cross-split row plus 2 shared
  train texts (2 rows per language) out of 96,668 pooled rows; negligible, but pooled leakage is not
  exactly zero.
- **No non-parallel topic control.** FLORES is parallel, so the all-langs FLORES model is not
  "more documents"; a non-parallel topic dataset would separate translation augmentation from
  language diversity.
