## 3. Bugs / risks

**B1. `--seeds` silently ignores all but the first value.** `:814`
`SEED = int(args.seeds.split(",")[0])`. `--seeds 0,1,2` runs seed 0 only and reports no warning.
Everything in E29 is n=1.

**B2. Toxic is undertrained and cannot early-stop.** Cap 400 steps x 32 = 12,800 samples = 53% of one
EN epoch (24,000 rows). With `max_epochs` effectively 1 there is one validation point, so
`PATIENCE` never fires. All four LR trials report `best_epoch=1, best_steps=400`. The JSON records
`toxic max_epochs 1`, which makes this permanent if the cap is ever re-derived from the JSON.

**B3. Toxic LR selection sits on the grid edge and is confounded with the step cap.** Val AUC rises
monotonically with LR (0.8884, 0.9089, 0.9181, 0.9262) because a larger LR travels further in the same
400 steps. The selected 1e-4 is the upper bound, so the optimum may be outside the grid, and the grid
does not measure LR quality, only speed under a fixed budget.

**B4. Toxic F1 is macro-F1, not F1(pos).** `:311-315`. The docstring (`:15`) and `EXPERIMENTS.md:350`
both say binary uses F1(pos). Measured gap up to +0.38 (section 1.7). Fix the doc or the metric, not
both silently.

**B5. Toxic metrics use a fixed 0.5 threshold while the rest of the repo tunes thresholds** (E27 uses
F1-optimal / precision@recall; E18 uses quantile matching). Cross-experiment F1 numbers are not
comparable, and transfer recall at 0.5 is 2.6-11.3%.

**B6. The 0.975 verdicts are inside the noise floor.** Bootstrap SE of one AUC (frozen model):
sent 0.0103 / 0.0156 / 0.0125 (en/it/de); agg 0.0207 / 0.0239 / 0.0245 / 0.0316 (en/it/de/fr);
toxic 0.0075-0.0156. The bar's tolerance is 0.017-0.023 absolute at AUC 0.7-0.9. For agg fr the ratio
SE is ~0.045, larger than the 0.025 bar itself. Only 6 fails out of 26 could be argued either way;
`sent de AUC 0.978` and `agg EN-self F1 0.981` are nominal passes with no margin.

**B7. FT test scores come from an unvalidated final run.** `do_val=False` at `:556-558` loads the last
epoch's weights. This is defensible, but it means the FT test column has no independent model
selection, while the frozen column is a single fixed fit. Combined with B6, no paired test exists
(no stored probabilities), so no CI or paired bootstrap is possible.

**B8. Non-determinism.** No `torch.use_deterministic_algorithms`, no cudnn flags, no prob dump. A
re-run cannot be expected to reproduce the FT cells exactly. The frozen cells are deterministic and
were reproduced bit-exactly.

**B9. Tiny multi-class test sets.** agg 139 rows, 11 classes, smallest class 4 rows; sent 505 rows, 12
classes, smallest class 4 rows (counts: [4,31,30,46,20,20,45,42,8,97,30,132]). Macro OVR AUC on these
counts is unstable, and a single flip moves accuracy by 0.7%.

**B10. `toxi_emb_610` branch is dead and fragile.** `:877` selects the embedding dir by
`"610" in MODEL_ID` (substring of the HF id). A `--model-id` that merely contains "610" elsewhere
would silently load the wrong cache.

**B11. `align_sentence_indices` has no duplicate check.** `:185-195` builds a dict keyed on
`(split, id, en)` and silently keeps the last duplicate. `train_flores12.py:290` raises on duplicates.
If a duplicate ever appears, FT and the frozen baseline would use different row maps.

**B12. The precision claim lives only in the JSON.** `:617-618` records `precision`, and
`write_report` follows it (`:650-652`), so a CPU or `--no-bf16` run is labelled correctly. But the
claim is not in `EXPERIMENTS.md`; if the JSON is ever regenerated on CPU, the log and the prose would
disagree with no cross-check. Low risk, cheap to record the resolved device and precision in the md
header.

## 5. Recommended changes

**Highest priority (changes a conclusion):**
1. **Report the tuned baseline.** Add `REPO_REF` (or a fresh Optuna run) as a third column. The
   current claim "fine-tuning improves EN-self" depends on comparing against a weak fixed XGB.
2. **Fix the toxic arm or withdraw its F1 claims.** Train to at least one full epoch (cap >= 750
   steps, `max_epochs >= 2` so there are >= 2 val points), let early stopping work, and extend the LR
   grid upward or fix it at 3.6e-5. Then report F1(pos) and recall at a stated operating point.
3. **Complete the table.** Put all 13 cells in `EXPERIMENTS.md`, with per-cell ratios, and state which
   definition of 0.975 is used.
4. **Add seeds.** At least 3, honour `--seeds` as a list, and report mean +/- sd. Report the
   bootstrap SE next to every ratio so that 139-row cells cannot be read as pass/fail.

**Protocol / fairness:**
5. Train in-language FT on train+val, like the EN arm and the frozen in-language arm, or make all arms
   train-only. Do not call the resulting number a "ceiling" until then.
6. Train the toxic frozen XGB on EN train+val (or train FT on train only) to remove the 3,000-row
   asymmetry.
7. Align truncation: use `MAX_LEN-1` in `fit`/`predict` to match `extract_embeddings.py`, or document
   the 512/511 difference and its 3% incidence.
8. Replace `toxi_emb_210` with `emb_bf16/toxic/210m` (the cache other experiments use), or commit the
   producing script.

**Hygiene:**
9. Write the exact command (with `--caps`) into the docstring, the md and `REPRODUCE.md`, and add the
   resolved caps to the JSON header from a single source.
10. Make the JSON/md/png be written by the same run; if a post-run rewrite is needed, use
    `--regen-report` and record it in the log.
11. Make `--seeds` a list or fail on more than one value; add `torch.use_deterministic_algorithms(True)`
    (or record that it is off) and dump per-cell probabilities.
12. Add the duplicate-key check to `align_sentence_indices`.
13. Drop `REPO_REF`'s per-cell numbers unless they are re-verified against `models_registry.json`; its
    E18 conflict (0.856 vs 0.9186) is unresolved.

## 7. Bottom line

The arithmetic in E29 is correct: every stored number reproduces, the md is a faithful render of the
JSON, and the stated five failures are real. The experiment is nonetheless **PARTIAL** for three
reasons: the command is undocumented, the toxic arm is capped at half an epoch with an edge-of-grid
LR, and the 0.975 verdict is applied to a single seed with cells as small as 139 rows. One failure is
missing from the preliminary list (agg EN->it AUC 0.927), two passes are within noise, and the toxic
F1 columns measure the majority class rather than toxicity.
