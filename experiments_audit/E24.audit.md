# E24 audit — More datasets (XNLI, PAWS-X, textdetox, SIB-200)

**Scope.** Read-only audit of `EXPERIMENTS.md:45-60` (E24), `more_datasets.py`, `more_datasets.json`,
`more_datasets.md`, and the cached inputs/artifacts. No repo file was edited. No model was retrained.
All Python checks were light (load JSON/Arrow/TSV, recompute ratios, count duplicates); the longest
took well under 3 minutes. No visible window was created.

**Bottom line.** The arithmetic is clean: all E24 numbers match the JSON/MD at 3 dp, and the JSON is
internally consistent. The **claims** are too strong. At the artifact's own dataset-level rule only
PAWS-X is comparable, and that pass is degenerate (both models are near chance). XNLI and SIB-200 are
2/3 targets; textdetox is 0/4. The entry also omits the English-only `global_z` result, which passes
PAWS-X too, so "per-language stats are necessary" is not universal. Finally, three of the four
datasets use translated/parallel target data, so task and data provenance are confounded.

## Discrepancies (entry vs artifact)

1. **The E24 finding overstates the dataset-level result** (`EXPERIMENTS.md:60`: "comparable for
   topic / paraphrase / NLI; fails for toxicity"). The artifact says XNLI = NO (de 0.898), SIB-200 =
   NO (es 0.896), PAWS-X = YES, textdetox = NO (`more_datasets.md:25`; JSON
   `summary.comparable`). Topic is 2/3 targets, NLI is 2/3, paraphrase is 3/3 but degenerate. The
   per-row checkmarks in the entry are correct; the one-line finding is not.
2. **The Master result overstates SIB-200** (`EXPERIMENTS.md:388-390`: "comparable ... for topic
   (... SIB-200)"). SIB-200's es ratio is 0.896, below 0.9. It should read "SIB-200 de/fr" or
   "2/3 targets".
3. **The entry omits the `global_z` PAWS-X pass.** The artifact's `global_z` (English-only stats)
   also clears 0.9 on PAWS-X: de 0.926, fr 0.914, es 0.903
   (`more_datasets.json` pawsx `summary.comparable.global_z=true`; `more_datasets.md:73`). This is a
   substantive omission: it is the no-target-sample control, and it passes. E18's "comparable iff
   per-language stats" (`EXPERIMENTS.md:42-43`) is therefore not a universal rule; on PAWS-X,
   English-only stats suffice. Caveat: E24's `global_z` is **L2 + English z**, whereas E18's
   `global_z` has no L2 (E24's `fit_z` always calls `l2norm`; `more_datasets.py:168-177`), so the
   PAWS-X pass could be driven by L2 rather than by the English z-statistics. The E18 claim was
   scoped to E18's datasets, but the "iff" wording reads generally.
4. **PAWS-X is presented as a success without its absolute level.** The entry's 0.602 EN-self and
   0.918–0.946 ratios are arithmetically right, but the task is near chance: AUC 0.5, target-trained
   AUC 0.584/0.587/0.599. This is a representation failure (mean pooling of a concatenated pair
   discards word order), not evidence of usable paraphrase transfer. The E24 table should show the
   target-trained reference and a chance baseline; the artifact has them, the entry does not.
5. **XNLI is weak in absolute terms.** EN-self macro-F1 0.440, target-trained 0.415–0.441 (accuracy
   0.441 vs 0.333 chance). The 0.898–0.949 ratios compare two modest scores. The entry should state
   this; otherwise "comparable NLI" sounds stronger than the evidence.
6. **Artifact label vs source data (not an entry-number): "native" is wrong for three datasets.**
   `more_datasets.md:9` and the detail-table headers (`:35,58,87,116`) call the target-trained column
   "native"; the JSON key is `native`. The E24 entry itself does not show this column, so this is an
   artifact-terminology issue; it affects the artifact's native/EN reference, not the entry's
   target/English ratios. XNLI train is translated MNLI (HF card; 392,702 train/lang, labels identical across
   languages), PAWS-X train is machine-translated (296,406 pairs total; 49,401/lang; HF card), and
   SIB-200 is Flores-200 parallel (same `index_id`/labels across languages). Only textdetox has no
   observed parallel-translation structure. The column should be "target-trained" or "in-language
   (translated train)".
7. **Status wording.** E24 is marked `DONE` (`EXPERIMENTS.md:45`), not "verified". The numbers are
   verified, but the interpretation needed qualification (this audit). "DONE (numbers verified;
   interpretation qualified)" is more accurate.

## Bugs / risks

1. **High — textdetox train/test leakage.** `_load_textdetox` (`more_datasets.py:271-298`) splits each
   language 80/20 with no deduplication. Reconstructing the split exactly (seed 0) gives these exact
   duplicate test texts that also occur in train, per 1,000 test rows: **en 32, it 6, de 125, fr 35,
   es 0** (normalized overlap is nearly the same: 33/7/127/38/0). The de test set is ~12.5% verbatim
   duplicates of train. This inflates English self (slightly), the target-trained de reference
   (substantially), and makes the split non-reproducible if the dataset revision reorders/changes
   rows. It does **not** directly leak into the English model's target test (cross-language identical
   texts = 0), so the textdetox transfer failure is not explained by this; but the native/EN reference
   is not clean.
2. **High — translated/parallel vs independent data is confounded with task.** XNLI, PAWS-X, and
   SIB-200 targets are translations of English (parallel; train labels identical, PAWS-X test labels
   aligned 0.994–1.000), and their `perlang_z`
   stats come from full translated train sets (20k/20k/701), not a small native sample. textdetox is
   the only dataset with no observed parallel-translation structure. The "topic/paraphrase/NLI pass, toxicity fails" contrast may reflect
   provenance/domain as much as language transfer. The experiment cannot separate these with the
   current four datasets.
3. **High — weak absolute scores are counted as passes.** PAWS-X EN-self AUC 0.602 (chance 0.5),
   target-trained 0.584–0.599; XNLI EN-self macro-F1 0.440 (accuracy 0.441 vs 0.333). A ratio >= 0.9
   on such weak absolute scores is not evidence of a working cross-lingual system. The entry should impose a minimum
   absolute performance floor (e.g., EN-self AUC >= 0.7 / macro-F1 >= 0.5) before calling a dataset
   comparable.
4. **Medium — cache key can silently reuse wrong embeddings.** `get_emb` keys on
   `dataset/language/split/count` only (`more_datasets.py:200-206`). It does not hash the texts and
   does not include the model, `MAX_LEN`, or dataset revision. A dataset revision with the same row
   count (especially textdetox's random split) would reuse stale embeddings with new labels. Add a
   content hash (SHA1 of the texts) and model/`MAX_LEN` to the filename, or store a manifest.
5. **Medium — no pinned HF revisions.** `load_dataset` / `hf_hub_download` calls
   (`more_datasets.py:234-235,257-258,274,307-310`) use the default main revision. The JSON `meta`
   (`more_datasets.json:1719-1751`) records model/config/seed/XGBoost but **not** the dataset
   revisions. The cache shows XNLI `b8dd5d7`, PAWS-X `4cd8187`, textdetox `0190754`, SIB-200
   `38977a6`. Pin them and record them.
6. **Medium — single seed, no CIs, borderline cells.** One seed and no confidence intervals; test
   sizes are 5,000/2,000/204/1,000. XNLI de 0.898 and SIB-200 es 0.896 are within noise of 0.9.
   SIB-200 es flips above 0.9 on **accuracy** (0.901) but is 0.896 on the headline macro-F1. Report
   bootstrap CIs / 3–5 seeds and treat borderline cells as uncertain.
7. **Medium — resumable JSON can keep stale results.** `run` skips any dataset already in the JSON
   (`more_datasets.py:629-631`). Changing `MAX_TRAIN`, model, or a loader and rerunning will keep the
   old dataset results while updating `meta`; only deleting the JSON forces a recompute. Add
   `--force`/`--overwrite` and document the delete-JSON behavior.
8. **Low — XNLI test is truncated from 5,010 to 5,000.** `MAX_TEST=5000` (`:109`) randomly drops 10
   of 5,010 test rows (`:236-238`); the artifact reports 5,000. Harmless statistically, but the
   official test size is 5,010; use all 5,010 or document the drop.
9. **Low — SIB-200 `--smoke` is not small.** `_load_sib200(smoke)` ignores `smoke` and uses the full
   701/204 (`more_datasets.py:301-323`); the smoke JSON confirms SIB-200 at 701/204. It also wrote
   full-size SIB embeddings during the smoke run, later reused (safely) by the full run. Honor
   `SMOKE_TRAIN`/`SMOKE_TEST` or rename the flag.
10. **Low — thresholded binary metrics are calibration-sensitive.** `accuracy`/`macro_f1` use 0.5
    (`more_datasets.py:333-337`); cross-language comparisons of those columns are not calibrated.
    The headline AUC is fine; label the 0.5 columns as "at 0.5, uncalibrated". `fpr_at_recall90`
    (`:346-347`) uses test labels to pick the threshold; it is an oracle metric and should be labelled
    as such.
11. **Low — exact launch argv/environment are not recorded.** The log/PID/status show a detached run,
    but not the command line, Python/transformers/XGBoost versions, or GPU/CPU. The docstring's
    command is the only reproduction hint. Write argv + versions into `meta`.
12. **Low — the external cache is part of the result.** Embeddings live in
    `%TEMP%\opencode\more_datasets\emb_cache` and datasets in `~/.cache/huggingface`; the repo alone
    cannot reproduce the numbers. Record the cache paths/revisions or make regeneration part of the
    run.
13. **Low — no per-example scores/models saved.** Only aggregate metrics are stored, so paired
    bootstrap, per-language error analysis, and duplicate-exclusion re-scoring require retraining.
    Save test scores (or models) for the headline config.
14. **Medium — `global_z` is not `raw`, and it differs from E18's `global_z`.** E24's `fit_z`
    always L2-normalizes (`more_datasets.py:168-177`), so `global_z` = **L2 + English z**, not a
    no-op relative to raw. E18's `global_z` is a per-feature z-score **without** L2
    (`proof_mean_alllangs.py:156-162`), so the two experiments' `global_z` are not the same config.
    The artifact has no `raw` or `l2` row; the PAWS-X English-only pass cannot be decomposed into
    L2 vs z effects. Add `raw`/`l2` rows or rename this config.

## Recommended changes

**P0 — fix the claims before the next report:**
1. Rewrite the E24 finding and Master result to match the artifact: XNLI 2/3 targets, SIB-200 2/3,
   PAWS-X 3/3 but degenerate, textdetox 0/4; dataset-level comparable = PAWS-X only.
2. Add the target-trained reference and a chance/absolute baseline to the E24 table; require a
   minimum absolute score (e.g., EN-self AUC >= 0.7 / macro-F1 >= 0.5) before "comparable".
3. Add the `global_z` PAWS-X pass (0.926/0.914/0.903) and qualify E18's "iff perlang_z" wording.
4. Fix the textdetox split: deduplicate/group by normalized text before splitting, report the
   duplicate rate, or use a fixed official split if one becomes available.
5. Rename "native" to "target-trained" and add a provenance column: translated/parallel (XNLI,
   PAWS-X, SIB-200) vs no observed parallel structure (textdetox).

**P1 — reproducibility and statistics:**
6. Pin HF revisions (`revision=`) and record them in `meta`; include text hash + model + `MAX_LEN`
   in the cache key.
7. Add `--force` and document "delete JSON to recompute"; record argv, package versions, device.
8. Run 3–5 seeds and bootstrap CIs; report whether 0.898/0.896 are distinguishable from 0.9.
9. Honor `--smoke` for SIB-200; use all 5,010 XNLI test rows or document the 10-row drop.
10. Label binary 0.5 metrics as uncalibrated and `fpr_at_recall90` as an oracle metric.

**P2 — design:**
11. Add a native, non-parallel dataset with an official split (or a native unlabeled sample for
    `perlang_z`) to separate provenance from task; textdetox is currently the only dataset without
    observed parallel structure.
12. Save per-example test scores/models for paired bootstrap and duplicate-exclusion sensitivity.
13. Add `raw` and `l2` rows; do not call E24's L2+English-z config `global_z` without noting that
    it differs from E18's no-L2 `global_z`.
